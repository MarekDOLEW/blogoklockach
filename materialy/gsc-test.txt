## Google Analytics 4 (scripts/ga4-raport.mjs)

Data: 2026-08-18
Polecenie: node scripts/ga4-raport.mjs --test
Kod wyjścia: 1 (test NIE przeszedł)

Uwierzytelnienie konta serwisowego działa (ten sam klucz co GSC), ale
Google Analytics Admin API jest WYŁĄCZONE w projekcie GCP (403 SERVICE_DISABLED).

Do zrobienia (projekt 763165814076):
1. Włączyć Google Analytics Admin API:
   https://console.developers.google.com/apis/api/analyticsadmin.googleapis.com/overview?project=763165814076
2. Włączyć Google Analytics Data API (potrzebne do raportów):
   https://console.developers.google.com/apis/api/analyticsdata.googleapis.com/overview?project=763165814076
3. W GA4: Administracja -> Zarządzanie dostępem do usługi -> dodać e-mail
   konta serwisowego z rolą "Przeglądający".
4. Ponowić: node scripts/ga4-raport.mjs --test
